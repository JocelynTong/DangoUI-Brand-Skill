# Brand knowledge (canonical source)

This directory is the repository-owned source for reusable task patterns, decision methods, adoption decisions, and reviewed cases. Each entry has a human-authored Markdown explanation plus a small structured record for checks; `public/knowledge/guide.html` and `public/knowledge/decisions.html` are generated from both by `npm run build:knowledge`, not separately authored. The current component definitions remain canonical in DangoUI; this catalog links to them instead of copying them.

Use `node skills/brand/scripts/query-design-knowledge.mjs list`, then read only the relevant `pattern`, `method`, `policy`, `decision`, `case`, `scenario`, `component`, or `recipe` record. Queries return the readable guide together with machine fields. A `pattern` is a reusable task contract; a `policy` is a reusable decision rule abstracted from cases; a `decision` records whether a particular token, asset, component or composition may be reused and at what scope. The older `scenario` remains the machine binding consumed by design-host. Evidence Agent uses source-selection before gathering facts; Brand Interpreter uses cross-page-token-promotion, design-asset-adoption and applicable policies; Design Director approves or blocks reuse.

Status matters: `pilot-candidate` patterns and methods guide review but do not approve source facts or visual direction; `blocked` decisions and `negative-regression` cases prevent known overreach. `validate-adoption-decision.mjs` checks the shared record and subject-specific fields, but does not confer approval. Current brand observations and candidates stay in migrations until they pass Evidence, semantic review, rendered application and independent QA. A source URL is a navigation reference, not a persisted screenshot or approved claim.

Near-term migration: the existing scenario catalog still lives under `public/knowledge/v0.1/`; its index is referenced from `knowledge/v0.1/index.json`. Move it behind a generated public projection only after the source/consumer contract is tested, rather than maintaining two hand-edited copies.
