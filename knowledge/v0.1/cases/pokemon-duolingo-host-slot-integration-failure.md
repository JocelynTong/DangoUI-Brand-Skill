# 真实牌组卡图被塞进生成槽位

## 发生了什么

多邻国画风接近后，三版头部分别把真实卡牌放进白色展示框、设备窗口和三格卡槽。用户认可画风改善，但认为卡牌嵌入很奇怪，随后对三处截图追问“这都是啥呀”。

问题不是再缩放几像素就能解决：白色槽位先于真实业务内容生成，卡牌只能作为后贴的证据图进入，出现双层边框、比例不匹配、尺寸不可读和缺少承托关系。

三张原始反馈截图已作为 H5 案例证据保存：双层展示框、设备槽硬塞、不可读的小卡证据。

## 当前只允许得出的结论

生图前先说明真实宿主内容在场景里的业务角色、原始比例、目标可读尺寸、承托方式和失败回退。AI 生成的空槽、相框或白板本身不算“已经支持真实内容”。如果真实对象只能靠无意义容器或不可读缩放进入场景，就退回方向设计，或把它留在 Productive UI。

这是同一宿主的一次负例，规则仍是 candidate，需要在独立品牌和宿主中验证。
