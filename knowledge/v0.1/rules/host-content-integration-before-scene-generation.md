# 先设计真实内容如何进入，再生成场景

只要 expressive 需要出现真实宿主内容，Host Strategist 就必须从宿主源码和渲染状态自动提取它在业务里是什么、原图尺寸和比例、当前显示尺寸以及最低可读尺寸。设计师只能引用这份冻结事实，并补充目标尺寸、承托方式、允许几层边框，以及失败时退回 Productive UI 还是重选方向；不能要求用户填写，也不能自行猜测源尺寸。

生成出来的空槽、相框、白板或设备窗口不算融合证明。若回填后出现双层边框、方槽塞竖图、内容小到不可辨认，或对象与环境只有统一阴影而没有语义和物理关系，应在概念门禁失败，不能继续靠 CSS 微调。

本规则仍是 candidate；它来自一个未获批的牌组搜索案例，需跨品牌和宿主验证。
