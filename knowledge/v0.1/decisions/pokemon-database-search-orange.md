# 决策：数据库 Search 橘色不得成为全局 CTA

**当前结果：阻断全局晋级。** 宝可梦卡牌数据库的 Search 按钮曾读到 `rgb(238, 107, 47)`，但这只能描述这个按钮当时的默认背景。它不是已批准的品牌主行动色，也没有获准映射到 DangoUI 全局 token。

这次补看了三个当前官网页面：首页 30 周年主视觉的探索按钮是白色，数据库 Search 是橘色，教学页抽样的内容入口是白色描边。它们做的事不同，并非同一职责的三个按钮；而且目前只读了默认态，没读悬停与焦点态。因此批准范围仍只停在**局部观察**，不能交给 design-host 当全局食材。[本次逐页读数](../../../migrations/pokemon-tcg-official/primary-color-live-review-2026-09-20.json)。

要重开这项决定，先找不同页面**做同一件事**的主按钮，补默认、悬停、焦点与禁用状态，再检查语义、对比度及 DangoUI 目标 token。最后还需设计负责人和独立视觉 QA 复核。没有这些，就保留这条阻断记录和对应失败案例，而不是换一个色值继续猜。
