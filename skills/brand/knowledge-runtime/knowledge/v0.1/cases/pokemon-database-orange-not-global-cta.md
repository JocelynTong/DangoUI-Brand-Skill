# 反例：把数据库的局部橘色推成全局 CTA

数据库 Search 默认态曾读到 `rgb(238, 107, 47)`，但匹配画面未完整持久化，Evidence 仍为 NEEDS_EVIDENCE。试装前没有完成官网身份入口及同职责行动对照，却暗示该色代表全站，用户也看不到本质改进。

后续三个官网页面汇总到 28 个黑白反相内容按钮，并各补至少一个可定位控件。这不等于 28 个逐项都有实物证据，也不证明内容浏览与数据库搜索属于同职责。首页冠军赛 CTA 的深色默认、金色悬停同样只有区块范围。

后来相同搜索任务从原生紫色试换为黑底白字；两维局部结构检查通过，六维品牌交接仍阻断，独立视觉及用户审美验收未完成。以上是同一案例连续修订，不算多个独立验证，也不批准黑白或橘色为全局 primary。
