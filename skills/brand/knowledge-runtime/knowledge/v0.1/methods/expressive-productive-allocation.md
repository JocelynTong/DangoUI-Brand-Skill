# 任务优先级与品牌表达的权衡方法

在同一真实任务、内容和视口下比较方案，先看收益与代价，再分配表达强度。

- 确认第一动作、访问频率、内容密度和可用空间；不预设工具只能朴素，也不预设首页必须有大主视觉。
- 找出来源中可迁移的构图、字形、材质或动效，并说明它在哪一刻帮助识别、探索或记忆。
- 比较至少两种方案的首动作距离、首屏结果、扫描与比较成本，以及从表达区进入任务区的方式。
- 生成前分别写清三个沟通目标：层级要把注意力带到哪里、用途要让什么功能不言自明、风格要让人感到哪些有来源证据的品牌属性。
- 验收分两关：先确认任务、惯用交互、真实信息与无障碍没有退步；通过后再比较第一印象是否在层级、用途和品牌气质上获得提升。
- 验收证据也要拆开：同一次固定视口渲染自动验证溢出、滚动、图片、结果几何与基础交互，并冻结首屏截图；独立视觉验收只读取这组哈希绑定截图判断层级、用途与风格，不再重复开浏览器，也不能换一套渲染证据。
- 多个方向必须是不同的机制假设，而不是同一骨架换色或换装饰；每个假设都要能在渲染结果中被独立证伪。
- 改变重复结果的相对尺寸或权重前，先检查宿主是否真的存在精选、排行、推荐或选中关系；没有证据时保持同级，把视觉焦点交给背景、入口和整体动线。
- 遮住显性品牌素材后检查剩余界面语言；是否需要继续强化，由任务与选定目标决定，不强制每个区域都夸张。
- 输出区域安排、采用及放弃理由、保护边界；在真实运行中交给独立验收确认。
