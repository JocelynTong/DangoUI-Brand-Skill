# 宿主表达方案的选择、还原与验证

- 检索匹配问题与旧案例，比较上下文差异并记录采用、调整或拒绝的理由；无适用证据时明确作为新假设。
- 先确定任务保护边界和各来源职责，再选代码、已有素材或生图；没有表达缺口时不强制生成。
- 生成简报分开品牌不变量、自由探索项、真实业务内容与空间预算。官网约束路线保持已有系统；自由生成路线选定后提取派生系统，不能冒充官网证据。
- 任何要进入 expressive 的真实宿主内容，都要在生图前绑定业务角色、原始比例、目标可读尺寸、承托关系和失败回退。生成空槽不算融合证明；出现双层边框、无意义容器或不可读缩放时退回方向设计或 Productive UI。
- 在同一坐标系核对对象轮廓、四角、承托面与遮挡。平面布局、分层遮罩或可靠三维资产按需求选择；底图几何变化后重新核对，不能沿用旧卡位。
- 比较素材与容器边界：有意分区保留分区，可重复纹理才平铺，不可重复场景采用受控裁切、延伸或底色衔接；检查长内容与不同视口。
- 冻结前做动态可行性试片；实施时逐组验证真实数量和映射，允许共享内容及空缺，不补假数据。几何稳定后再加动效，核对固定层、手势、聚焦、滚动与减少动态效果状态。
- 分别报告功能、几何、视觉及用户反馈。失败定位到最早错误节点：任务回分析、方向回设计、还原回实现、证据不足补验收。
