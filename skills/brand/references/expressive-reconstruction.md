# apply-host：expressive 判断、生成与动态还原

适用：apply-host 阶段需要判断 expressive 表达的可实现性、生成配套场景素材，并落地为可替换业务内容的动态 H5。已冻结方向内的素材生成不等于重新选方向；若需改变冻结构图，应显式退回方向修订。不是任意品牌自动设计承诺，也不将生成图晋级为官网品牌证据。

## 开始前冻结
- 保存参考图、目标视口、来源/生成属性与文件 hash。
- 从本任务记录空间预算：导航、场景、查询、结果各占多少；不要把本案例的比例当通用规范。
- 在参考图坐标系标记每个动态对象的四个角、前后顺序、承托面、遮挡边界。禁止三种不同构图共用一套扇形参数。
- 记录已选图的材质、光源方向；承认生成图存在不能由二维层准确复原的反射/折射。

## 制作
1. 生成/提取去掉业务内容的空场景，保留相同相机和结构。拆图后重新核对坐标，生成模型可能改变几何。
2. 对象使用四角映射，不以任意 rotate 值猜透视。固定环境、动态内容、前景遮罩、反光必须分别可开关。
3. 前景遮罩覆盖槽位/接触面，而不是给整张卡加阴影就声称融合。
4. 全部动态槽位绑定同一个业务对象。无真实数据时明确示例。引用参考图卡面的状态仅可作对照，不能用它证明真实数据替换成功。
5. 静态几何确认后增加动效：内容统一更新，环境固定；场景动效不移动导航与查询。减少动态效果模式关闭非必要运动。

## 可执行辅助
`node skills/brand/scripts/render-layered-scene.mjs manifest.json output.html`

清单包含 canvas [w,h]、background、slots [{id,quad:[[x,y]×4],z}]、groups [{id,cards:[URL]}]。每组卡面数须与槽位相同。输入明确遮挡边界；渲染器默认以空场景重新覆盖动态孔洞之外的区域。反光及复杂前景需另定义，不能从四角自动推断。

## 自检顺序与失败定义
- 在同尺寸下分别检查背景、卡面和前景，不能只比较整页平均像素误差（大面积相同底图会掩盖卡位错误）。
- 为四角位置保留独立参考标注；读取真实 DOM 投影角点，按画布尺寸归一化，对照标注。不得从待测清单再生成“期望值”。
- 至少两个屏宽：场景宽度占宿主宽度的比例符合约定；防止固定高度与 aspect-ratio 相互压窄。
- 全部组逐一切换，核对每个槽位对应预期数据。测试数据无共享卡时每槽都应变化；真实牌组允许共享卡，禁止把“必须全部不同”当业务规则。
- 前景不拦截手势。验证触控、鼠标、圆点切换；减少动态效果模式不得留下持续动效。
- 工具页面记录首屏结果实际可见高度；空态只能证明布局，不能证明真实结果流可用。

## 报告边界
分别报告：几何/响应式、数据绑定、动效行为、素材融合人工检查、独立审美判断。已知案例重建通过只是方法回放；复用原标注不是独立设计或新案例泛化测试。

先指出失败及可修范围。不要用构建通过、运行脚本通过或参考图卡面看起来一致，替代视觉验收。

## expressive 生成前：动态可还原性（2026-09-20 本项目偏好）

本项目用户明确要求：今后少出前后景复杂、需多重遮挡才能成立的方案。默认优先单一承托面、清楚的卡片边界、少量独立前景；表达强度优先来自材质、光照、色彩与构图。不是禁止所有复杂场景，也不是跨项目通用审美结论。

- 给生图的简报分开写：品牌已证实的不变量、仅适用某页面的机制、可自由探索项、宿主功能与首屏预算。不能把某一首页的黑底或某一方案的卡套升级为共用规则。
- 提案同时检查：动态对象的可见边界、承托面、遮挡依赖。若需要多个局部纸槽/折射/交叉遮挡才能成立，默认降级为备选，优先换成层级清楚的构图，不等 H5 失败再不断补蒙版。
- “背景—动态对象—少量固定前景”可以作为低复杂度起点，不是固定层数上限。若复杂遮挡就是用户明确选定的核心表达，需先证明单组静态替换成立，再拓展换组。
- 空场景拆图改变了承托面或折纸结构时，原图四角坐标不再足够；应重新生成匹配背景或换案，不得把新底图上贴旧坐标宣布为还原成功。
- 参考图与场景资产在同一坐标系裁切。避让导航应调整整体画面或 UI，不能只缩小动态对象，破坏它与环境的尺度联系。
- 单独记录功能验证和人的视觉验收。纸艺前景补丁通过换卡测试，但用户仍判断“不太行”；保留此失败，不把它作为成功模板。

案例复盘见项目 `experiments/brand-constrained/retrospective.md`。这些约束待下一独立品牌/宿主检验；同品牌六个方向不算六个独立案例。

## 已有运行检查与接入边界
`check-expressive-runtime.mjs` 导出浏览器 DOM 测量与硬性断言，阈值来自宿主约定；调用者必须在失败时停止。当前实验 `experiments/brand-constrained/verify.cjs` 已消费，正式 apply-host 入口尚未接入。它不判断透视与阴影质量，也不能验证自报的品牌来源。`check-expressive-runtime.test.mjs` 验证错误拒绝；实验 `fault-runtime.cjs` 验证真实 DOM 故障被捕获。
