品牌工作流 · 角色树

按阶段自上而下阅读；缩进表示子阶段或分支。点击分支可收起。

  • Design Director / Orchestrator · 设计负责人 / 编排冻结目标、组织派发、处理回退与最终验收贯穿全程，不替代各角色的专业判断；生图引擎和脚本属于工具。
    • Pipeline 1 · learn-brand — 学习品牌
      • 1 · Evidence Agent来源取证采集页面与状态，建立可追溯事实。
      • 2 · Brand Interpreter解释品牌语言，查询决策库区分品牌不变量与场景限定规则。
      • 3 · Demo Designer构建学习能力 Demo用新页面证明能迁移品牌系统。
      • 4 · Blind QA / TPP独立验证来源、结构与生成能力失败退回最早责任节点；通过的品牌产物交给 Pipeline 2。
    • Pipeline 2 · 宿主应用 — design-host → apply-host
      • A · design-host — 判断、试片与选案
        • 5 · Host Strategist读宿主任务 → 查决策库 → 逐区域分配表达强度明确主要行动、动态内容与首屏预算；不默认首页必须有 hero。
        • 6 · Brand Application Designer按区域选择表达手段
          • none · 不增加 expressive功能优先，记录为什么不需要加强表达。
          • existing · 现有素材 / 代码使用品牌系统与已有资产形成候选方向。
          • generated · 生图分支
            • Brand Application Designer区域简报与拆分风险判断锁定品牌及业务约束，明确生成自由度；复杂遮挡默认降低优先级。
            • 工具 · 图像生成引擎，由应用设计角色调用生成候选场景与配套素材
            • Brand Application Designer隔离动态 H5 试片与运行自检替换真实结构的数据，验证空间关系；此时不修改正式宿主。
        • 7 · Host Visual QA独立复核候选 / 动态试片融合或透视失败 → 应用设计；区域分配错误 → 宿主策略。
        • 工具门 · validate-host-expression校验决策引用、输入与交接证据generated 额外要求概念图、H5 和绑定版本的运行/视觉记录。缺失、过期或视觉拒绝 → 停止。
        • 8 · 用户 ＋ Design Director / Orchestrator用户选案 → 编排者冻结方向和输入概念图与动态效果一起确认，实施时不能静默换案。
      • B · apply-host — 实施与验收
        • 工具门 · 表达计划复核 + 原有冻结设计检查确认交接输入齐全且未过期
        • 9 · Host Implementation Agent在真实宿主实施冻结方向负责素材、响应式、数据、图层与交互；保护业务。无法还原则报告缺口并退回。
        • 10 · Host Visual QA独立检查真实宿主验证业务安全、视觉保真与运行效果；按原因退回实现或上游设计。
        • 用户最终验收
      • 11 · 原决策角色记录；Design Director / Orchestrator 组织复盘回写决策库 → 下次判断前检索保留依据、取舍、反例与反馈；候选经验不因单次成功自动升级。
状态边界：交接门已接入口；角色树不是自动调度已完成的声明。生图与试片由 agent 执行。真实宿主端到端、跨品牌效果和安装同步尚待验证；脚本通过不等于审美通过。
