# Arena integrated art — test line A

目标是还原 `high-fidelity-direction-board-v2.png` 左侧 A 的完整竞技场群像，而不是把角色贴到普通背景上。

## 结论

本轮最强的可直接复用资产是 `candidates/arena-background-v1.png`：竞技场透视、红蓝对峙光、观众密度和前景遮挡关系都成立。`candidates/lightning-overlay-v1.png` 是带透明通道的可复用能量层。

两张完整场景合成均只可作测试证据，不能进入宿主：

- `hero-integrated-composite-v2.png` 叙事完整，但本地 Pikachu 只有 280×276，放大后与 3D 场馆质感不一致；对手来自方向板局部恢复，仍有背景污染。
- `hero-source-recovery-v2.png` 的角色比例最接近 A，但有 UI 残留和遮罩断层。

因此生产结论为 **FAIL**。若把任一合成直接交付，会重复用户已经指出的“贴纸感”。

## 已验证的可实施构图

- 场馆使用单一中央消失点，角色都落在同一个擂台轴线上。
- 蓝光来自左侧、红光来自右侧、黄色电光从前景角色向外反射。
- 前景观众必须压住主角下缘；对手必须有擂台接触点，不能悬空。
- 主角约占画高 40–45%，对手约占 18–22%，两者与观众形成三层景深。

## 下一步的最小条件

只缺一张可合法生成或提供的高分辨率、无 UI、无文字角色群像，或两张高分辨率透明角色源。场馆底图和闪电层已经可直接承接，没必要再重做背景。
