# Arena Night A 独立视觉 QA

这套 Gate 用于筛掉“元素都对，但画面不成立”的结果。评审对象是用户实际看到的 `390×844` 宿主首屏，不是代码、资产清单或设计说明。

## 当前结论

用户截图得分 **43/100，FAIL**。命中三个不可补偿的硬失败：

- `STICKER_COLLAGE`：赛事照片、皮卡丘与卡牌是独立贴图，没有形成同一事件。
- `A_CONTRACT_REPLACED`：保留了黑、黄、角色和卡牌，却丢失 A 的竞技群像、对抗关系与爆发瞬间。
- `SCENE_LIGHT_MISMATCH`：摄影背景、3D/卡通角色和卡牌的光源、黑位、清晰度与材质不属于同一空间。

因此，继续移动位置、放大皮卡丘、增加卡牌或光效都不会过 Gate。下一轮必须先解决“完整场景”而不是“更多品牌元素”。

## 放行规则

- `PASS`：总分至少 82；无硬失败；每个核心维度达到自己的最低分。
- `REVISE`：72–81；无硬失败；没有核心维度低于该维度 60%。
- `FAIL`：低于 72，或命中任一硬失败。
- 构建成功、成功导入小程序工具、Logo、品牌色、官方素材和业务功能都不能抵消视觉硬失败。

## 每轮怎么用

1. 固定同一路由和 `390×844` 视口，保存一张全新的首屏截图。
2. 先遮掉 Logo 和 Pokémon 明文，判断群像、空间、光源和竞技语义是否仍成立。
3. 与 `high-fidelity-direction-board-v2.png` 的 A 方案等高并排。
4. 按 `arena-a-visual-rubric.json` 七个维度逐项打分并检查硬失败。
5. 未达到 82 分不提交用户；将问题退回对应 owner 后重新实现、重新截图、重新 QA。

## A 方案最低视觉结构

下一候选至少同时具备：

- 一个明确主角；
- 一个与主角发生关系的对手、伙伴或环境力量；
- 可读的前景、动作层和竞技场/观众背景；
- 统一的主光、轮廓光、爆发光与空气感；
- 一处主标题和一个主任务入口，且不遮挡主体；
- Logo 遮蔽后仍然能读出“收藏卡牌竞技世界”。

“一张背景＋一个孤立角色”不满足群像条件；“背景＋角色＋浮动卡牌”也不会自动满足。
