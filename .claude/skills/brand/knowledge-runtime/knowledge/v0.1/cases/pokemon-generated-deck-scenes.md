# 宝可梦生成场景：结果与失败

本记录来自同一宝可梦牌组广场的连续调试，六个方向只算一个案例。场景是生成提案而非官网证据；方法为候选，不能视为跨品牌审美保证。先对照当前宿主任务、动态内容、首屏预算及素材条件，明确采用、调整或不采用的理由。用户纠正和反例应追加到修订记录中，不覆盖旧反馈。没有命中经验时明确是新问题，不编造先例。技术检查只能证明运行下限，人的视觉否决不能被脚本通过抵消。

用户对B/C透视调整后反馈：“嗯，看着好多了，再随机试试三个方案吧”。纸艺补前景后反馈：“还是不太行，以后少出这种前后景复杂的”。

原因复盘：生图简报过度限定黑底/卡套；独立缩卡破坏场景尺度；拆图重建折纸结构后继续用旧坐标；缺少前景遮挡。恢复坐标和接触阴影改善B/C，纸艺仍未通过。

反例边界：固定插画或已有可靠分层素材时，复杂前景仍可成立。本轮没有验证无hero首页，也未跑第二独立品牌。
