# OPCG A1：背景断层与动态卡牌遮挡修复

用户认为官网学习的色彩在这次比较中更稳定，接受多数效果，但指出长列表背景突然结束、卡牌缺少前后景关系。这是有限案例观察，不能证明某条视觉来源路线普遍更好。

背景末端改为与纸面底色衔接。卡牌修复采用人工标注木沿和牌匾轮廓，把动态卡牌放在底图与前景之间，移除额外金边；标准圆角裁切不等于自动轮廓识别。

换组检查又发现 H5 按钮聚焦造成舞台内部滚动，前景和底图错位；改为 overflow:clip 后复核。此 CSS 选择只代表本实现，不保证其他平台兼容。

H5 检查了 2/3/1 张真实卡的切换与对齐；原生430宽独立检查了遮挡、箭头和滑动。最后 overflow 变更后原生未再复查，原生375与真机本轮未测，用户最终视觉批准未记录。另一品牌仍使用同一宿主，不计跨宿主成功。
