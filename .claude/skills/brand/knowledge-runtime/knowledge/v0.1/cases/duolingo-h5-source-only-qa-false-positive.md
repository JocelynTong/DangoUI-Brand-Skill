# 反例：源码数到品牌机制，渲染仍是通用工具页

Duolingo 的 H5-first 测试保持了宿主的搜索、筛选和列表，也诚实使用 schema/loading 状态。独立 QA 从源码数到角色、对话气泡、厚底按钮、圆角和反馈动效，因而判定值得继续。

实际打开最终首屏后，主体仍是大片白色通用表单和列表；小素材贴片不足以形成品牌视觉主体，其中学习示意图还被当成身份表达。设计负责人因此在交给用户前否决结果。

这次问题不是 Productive 结构错误，而是把“代码里写了机制”误当成“用户看到了有效构图”。后续 QA 必须打开最终渲染首屏，遮住显式品牌名复核第一眼，并检查每项素材是否承担 Brand MOD 声明的视觉角色。
