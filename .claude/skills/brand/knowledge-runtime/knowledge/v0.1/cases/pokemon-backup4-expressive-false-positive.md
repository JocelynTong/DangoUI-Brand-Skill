# 反例：宝可梦入口有品牌，任务区失去表达

一次 fast design-host 在 239.084 秒内通过机器检查。Field Search 和 Card Index 是同一轮两个备选，不是两个独立案例。旧记录保留预选器推荐 Field Search，但没有完整的当时选案理由；以下解释属于事后复盘。

Field Search 从官方氛围进入普通渐变卡片，Card Index 从官方卡牌进入通用白列表。用户视觉不满意，两案未获批准；素材载入、结构差异与显著度检查没能发现这种表达断裂。

此次误判是把“入口用了品牌素材”当作“任务过程保留了品牌语言”。它推动了“品牌表达可延续到真实任务内容”的候选，但没有提供正向泛化证明。
