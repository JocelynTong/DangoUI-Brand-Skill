# 先决定看哪些页面，再开始采样

官网不是一张统一皮肤。首页通常负责让人认识品牌，工具页负责完成任务，学习页负责解释内容。同一个品牌在这些地方可以有不同按钮、密度和素材安排。Evidence Agent 的工作是把这些差异如实带回来，不是挑一个最容易采集的页面代表全站。

## 怎样做

- 先把本次目标翻译成问题：要学习品牌入口、检索任务，还是教学层级？
- 给每个问题列出应该看的页面和状态。首页没有因为工具页更易量化就自动出局。
- 每条观察都带页面、区域、控件、状态与可见证据；打不开的页面写明缺口和替代来源的局限。
- 把“看到了什么”交给 Interpreter；不要在取证时替它命名全局 token。

## 宝可梦的教训

卡牌数据库适合证明 Search、Reset 与筛选如何工作；TCG 首页更适合观察品牌入口与主视觉。数据库 Search 按钮的橘色是真实的局部读数，却不能替首页回答“品牌主 CTA 是什么”。

## 交给下一步时

下一位应能看见每个来源为什么被选、还缺哪些页面与状态。缺口不能藏在“采样数很多”之后。本方法仍为候选流程，不等于任何品牌事实已经获批。
