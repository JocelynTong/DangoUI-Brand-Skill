# 什么时候把一次观察变成可复用知识？

知识库不是“记录过就默认正确”。一条内容可以是候选、局部获批、全局获批、驳回或退役；人在阅读时必须一眼知道它处于哪一步。

## 设计负责人的签字

- 先读原始证据、跨页面冲突、适用和禁用场景，而不是只读漂亮的 Demo。
- 在记录里写明批准的最窄范围、审阅人、决定依据和来源版本；不确定时保留候选。
- 经真实页面试装和独立 QA 后，才考虑晋级可复用配方。用户指出视觉不符，即使脚本通过也要回到失败节点。
- 来源变化或旧结论被推翻时，保留历史，标记失效并回归依赖它的下游。

## 谁不能代签

Evidence Agent 只交事实；Interpreter 提解释；脚本拦缺项。它们都不能代替设计负责人对语义范围和视觉质量签字。人类审美验收也不能被“所有字段填齐”替代。
