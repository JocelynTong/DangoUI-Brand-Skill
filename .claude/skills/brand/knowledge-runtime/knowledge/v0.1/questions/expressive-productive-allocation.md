# 面对真实任务，品牌表达该加强在哪里、收敛在哪里？

这是一类反复出现的**决策问题**，不是某一次设计结论。每个独立案例都应记录自己的任务条件、两个以上可行方向、当时的选择与理由、实际验收结果。一个案例里的多个设计方向只是备选，不会让案例数增加。

## 目前学到了多少

现在只有「宝可梦备份 4」一个历史反例。Field Search 和 Card Index 是同一轮里的两个方向；两案都不批准，是这一个案例的事后判断。它提醒我们：入口有品牌素材、机器门禁通过，仍可能在真实搜索和结果区失去品牌表达。

从这个反例提出了「品牌机制延续到任务内容」的候选假设，但没有独立正向案例证明它普遍成立。它可能在另一个场景成立，也可能被一个有意保持安静、却仍获用户认可的高频任务页面推翻。不能把它写成每页必须执行的视觉配方。

## 案例怎样变成专家能力

下一次遇到同一问题，先用决策方法比较任务频率、首个动作、来源品牌机制及各方案的注意力成本，再记录人的真实反馈。随着不同案例增加，比较**哪些条件导致不同取舍**，形成有适用范围和例外的条件化判断。案例数量本身不是投票；没有跨情境验证与审阅，就维持候选状态。

橘色 CTA、品牌主色如何定，是另一类决策问题。它的案例不能算作这条 expressive / productive 议题的第二例。
