# 调试产物生命周期

每次试跑先执行 `node skills/brand/scripts/brand-artifacts.mjs init --host <绝对宿主路径>`。返回独立 `buildDirectory`；构建与临时预览写入这个新目录，不把新输出叠到旧 dist，也不在宿主增加测试页面。清单记录创建时间，可用于耗时统计；不是 token 或费用统计。

- 宿主保留业务代码、运行素材及当前交接指针；复用案例证据在正式知识库集中保存。
- `protect --id <id> --reason <依据>` 保护已选方案、验收证据或知识库引用。引用写入知识库前先保护来源；长期证据应从系统临时目录迁至持久归档，并更新路径与哈希。
- `finish --id <id>` 标记停止写入；失败结果也可以结束，但不是验收通过。
- `list` 查看记录；`quarantine --id <id>` 只移走已结束且未保护的运行，`restore --id <id>` 恢复。默认不永久删除，也不自动按日期删。
- 所有命令支持 `--root <集中目录>`。默认系统临时目录适合试跑，不保证长期保存。

脚本只管理自己创建的运行，不扫描或删除宿主源码。保护依赖显式登记，不能声称自动识别了所有外部引用。历史目录需先审计引用再隔离；重复哈希本身不是删除依据。不要清理正在服务的预览。共享图片不要直接改为硬链接后继续覆盖写入，以免联动修改多份证据。
