# 临界 runtime-only 分发包

仅供 Vue Web 局部组件试用，状态仍为 candidate。四个 kit 文件保持原始字节与 SHA-256，不携带 Figma 截图或私有捕获路径。`distribution.originalCompleteManifestSha256` 追溯原完整 manifest；`unbundledEvidence` 明确证据未随包提供，没有重新验证来源。原完整包和历史证据保持不变。

请通过 `../portable-web-example/prepare.mjs` 使用现有公开 install-web-trial 安装。小程序、后端、完整品牌与生产环境均未认证；禁止把未附截图当作验收通过。
